    關於 / 操作說明

    遊戲玩法

    從題庫選一份題目，每題會顯示題幹與 2~4 個選項，點選你認為正確的答案。答完會顯示對錯，按「下一題」繼續，全部答完顯示結算。

    Mac 鍵盤快捷鍵

    • 1 / 2 / 3 / 4 或 A / B / C / D — 選擇答案
    • Enter 或 空白鍵 — 下一題 / 開始 / 再玩一次
    • Esc — 退出 / 返回上一層
    • / — 在題庫列表中聚焦搜尋框

    iOS 上的安裝（加到主畫面變 App）

    1. 用 iPhone Safari 開啟此頁面
    2. 點下方分享圖示
    3. 選「加入主畫面」
    4. 從主畫面打開時會以全螢幕模式執行，看起來就像原生 App
